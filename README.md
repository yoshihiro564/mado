# 販売窓口ポータル（阪急バス）

阪急バスの定期券うりば・案内所・委託窓口を一覧にし、窓口ごとに写真を管理するページです。GitHub Pagesで公開します。

## 構成
```
index.html            ページ本体
data/windows.json     窓口一覧（公式サイト「販売窓口一覧」より）
data/photos.json      写真の一覧（窓口ID・ファイル・タグ・説明・撮影日）
images/<窓口ID>/      写真（長辺1280px・位置情報なし）
tools/prepare_photos.py  パソコンで写真をまとめて整えるスクリプト（任意）
```

## 公開
Settings → Pages → Branch: `main` / `(root)` → Save

## 写真の追加
ページの「写真登録」タブ → 縮小・ぼかし → ZIP → `images` と `data` をアップロード。詳しくはページの「使い方」タブ。

## 注意
- 公開リポジトリです。人が判別できる写真、社内事情は載せない。
- 元の写真（位置情報付き）を直接コミットしない。
